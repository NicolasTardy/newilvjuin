1. En bref

L'outil produit des ILV (affichettes) de crédit prêtes à imprimer, au bon format et avec les mentions légales à jour. Le principe est toujours le même :

  1. On choisit un ou plusieurs produits (par code EAN, à la main, à la douchette, ou en série).
  2. Ils arrivent dans le panier, où l'on ajuste au besoin le crédit, la garantie, la livraison.
  3. On clique « Générer les ILV » : l'aperçu s'affiche et le fichier se télécharge.
  4. On imprime.
Deux réglages à connaître se trouvent tout en haut, dans la barre « Impression » : le format (A5 par défaut) et la sortie (un seul PDF, ou des fichiers séparés).

2. La barre « Impression » (en haut de l'outil)

Elle s'applique à toutes les générations, quel que soit l'onglet utilisé.

RéglageOptionsÀ quoi ça sert
FormatA5 (défaut) · A4 · A3Taille du PDF imprimé. A5 correspond au schéma d'implantation magasin.
SortiePDF unique (défaut) · Fichiers séparés (ZIP)PDF unique = un seul fichier avec toutes les ILV (1 par page) → une seule impression. ZIP = un fichier par ILV.
Pour imprimer plusieurs ILV en une fois, laissez « PDF unique » : vous ouvrez un seul fichier et lancez une seule impression.

3. Les 5 façons de choisir des produits

🔎 Sélection EAN

La méthode la plus courante. Tapez un code EAN ou un nom de produit dans le champ « Filtrer », puis cliquez le produit dans la liste : il s'ajoute au panier. Des filtres (Domaine, Rayon, Gamme, Promo…) aident à réduire la liste.

✏️ Saisie manuelle

Pour un produit absent de la base ou un prix particulier : renseignez désignation, prix et rayon, puis ajoutez au panier.

📷 Scan magasin

Branchez une douchette code-barres, cliquez dans le champ de scan, puis scannez les produits : chaque code lu est ajouté automatiquement au panier avec les réglages par défaut. L'historique des scans s'affiche dessous.

  • EAN inconnu → message d'erreur (rien n'est ajouté).
  • EAN déjà scanné → signalé pour éviter les doublons.

📚 Impression en série NOUVEAU

Pour générer beaucoup d'ILV d'un coup. Filtrez par Domaine / Gamme / Rayon / Famille et par prix mini / maxi ; le nombre de « Produits concernés » se met à jour. Cliquez pour tout générer selon les règles habituelles.

🗞 Impression dépliant

Pour générer les ILV d'un dépliant publicitaire. Choisissez le N° de dépliant (média), éventuellement la Gamme pub, et un prix mini. En période de 10× sans frais, le 10× intérêts remboursés est automatiquement remplacé par le 10× sans frais.

4. Le panier

Chaque ligne = un produit. Vous pouvez y ajuster :

ColonneCe que vous pouvez faire
PrixLe corriger si besoin (le crédit proposé s'adapte).
GarantieCocher pour l'inclure (montant affiché selon le produit).
LivraisonCocher « Dom » pour inclure la livraison à domicile dans la mensualité.
CréditCocher le(s) type(s) de crédit à imprimer. Celui adapté au prix est pré-coché.

La croix rouge à droite retire la ligne. Puis « Générer les ILV ».

  • Vous pouvez toujours cocher un autre crédit que celui proposé : plusieurs cases cochées = plusieurs ILV générées pour le produit.
  • Le 5× sans frais est limité à 3 000 € (case grisée au-delà).

6. Garantie & livraison

  • Garantie : cochez la case sur la ligne du panier. Le montant est déterminé automatiquement selon le rayon et le prix. Trois niveaux existent (1★ / 2★ / 3★) selon les cas.
  • Livraison : cochez « Dom » pour l'inclure. Elle est alors intégrée dans la mensualité affichée.
  • Chaque ILV existe en 3 variantes selon ce qui est coché : garantie + livraison, garantie seule, ou sans service.

7. Générer & imprimer

  1. Vérifiez la barre « Impression » en haut : A5 + PDF unique pour le cas courant.
  2. Cliquez « Générer les ILV ». L'aperçu de chaque ILV s'affiche sous le panier.
  3. Cliquez le bouton violet « Télécharger le PDF unique » (ou le ZIP selon votre choix).
  4. Ouvrez le PDF et imprimez en A5 (dans la boîte d'impression, format A5, « Taille réelle » / 100 %).
Le fichier téléchargé porte l'extension correcte automatiquement : .pdf pour un PDF unique, .zip pour des fichiers séparés.

8. Questions fréquentes / dépannage

Le fichier téléchargé ne s'ouvre pas dans Acrobat (« fichier endommagé »)

Rechargez la page sans le cache : Ctrl + F5 (Windows). Régénérez ensuite vos ILV. Cela met à jour la version de l'outil dans le navigateur.

J'ai choisi « PDF unique » mais j'obtiens un ZIP

Même chose : Ctrl + F5 pour recharger la dernière version, puis relancez la génération.

Un produit n'apparaît pas dans la liste

Vérifiez l'orthographe / le code EAN, et que les filtres (domaine, rayon…) ne sont pas trop restrictifs. Si le produit est vraiment absent, utilisez l'onglet Saisie manuelle.

Le crédit proposé ne me convient pas

Décochez-le et cochez le crédit voulu dans la colonne Crédit du panier. Vous pouvez en cocher plusieurs.

L'ILV s'imprime trop grande / trop petite

Vérifiez le Format dans la barre « Impression » (A5 pour l'implantation magasin) et, dans la fenêtre d'impression, choisissez « Taille réelle » (100 %), pas « Ajuster ».
